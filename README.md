# 🗂️ QA Portfolio

> 🟢 Repositório em desenvolvimento ativo

Repositório com estudos e projetos em Quality Assurance, cobrindo testes manuais, automação, API e documentação de qualidade. Cada pasta representa uma área de atuação com materiais práticos e aplicados.


```
portfolio-qa/
├── 📁 testes-manuais/
│   ├── casos-de-teste/
│   └── relatorios-de-bug/
├── 📁 automacao/
│   └── playwright-python/
├── 📁 testes-de-api/
├── 📁 documentacao/
│   ├── planos-de-teste/
│   └── checklists/
└── 📁 projetos/
    └── estudos-de-caso/
```

## 🔍 Áreas cobertas

| Área | Descrição |
|------|-----------|
| 🧪 **Testes manuais** | Casos de teste estruturados, bug reports e análise exploratória com foco em cobertura e rastreabilidade |
| 🤖 **Automação** | Scripts com Playwright + Python para automação de fluxos web, seguindo boas práticas de organização |
| 🔗 **Testes de API** | Validação de endpoints REST, análise de respostas e cenários de erro com Postman |
| 📋 **Documentação** | Planos de teste, checklists de qualidade e relatórios de defeitos com linguagem clara e objetiva |
