# 🐛 Relatórios de bug

Registros de defeitos encontrados durante sessões de teste, seguindo um padrão profissional de documentação.

> 🌱 Em construção — primeiros relatórios sendo adicionados.

Cada relatório contém:

- Título objetivo do defeito
- Ambiente de teste
- Passos para reproduzir
- Resultado obtido vs. resultado esperado
- Severidade e prioridade
- Evidências (prints ou vídeos quando possível)
