# 📋 Casos de teste

Casos de teste escritos para praticar cobertura de funcionalidades, seguindo boas práticas de documentação em QA.

> 🌱 Em construção — primeiros casos sendo adicionados.

Cada arquivo representa um conjunto de testes para uma funcionalidade ou sistema específico, contendo:

- ID do caso de teste
- Pré-condições
- Passos para execução
- Resultado esperado
- Status (passou / falhou / bloqueado)
