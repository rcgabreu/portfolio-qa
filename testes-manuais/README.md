# 🧪 Testes manuais

Pasta dedicada à prática de testes manuais, incluindo criação de casos de teste e registro de bugs encontrados durante a análise.

> 🌱 Área em construção — os materiais estão sendo desenvolvidos conforme meu aprendizado avança.

## O que vai ter aqui

- **casos-de-teste/** → Casos de teste escritos com base em requisitos e cenários reais ou simulados
- **relatorios-de-bug/** → Registros de defeitos encontrados, com descrição, passos para reproduzir, severidade e evidências

## Habilidades sendo desenvolvidas

- Análise de requisitos para criação de casos de teste
- Técnicas de teste: partição de equivalência, valor limite, teste exploratório
- Escrita clara e objetiva de bug reports
