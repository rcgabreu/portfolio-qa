# 🔗 Testes de API

Pasta dedicada à prática de testes em APIs REST, validando endpoints, respostas e cenários de erro.

> 🌱 Área em construção — estudando os fundamentos de APIs antes de adicionar os primeiros testes.

## O que vai ter aqui

- Coleções do Postman com testes organizados
- Cenários de validação de status, headers e body
- Testes de cenários de erro e fluxos negativos

## Habilidades sendo desenvolvidas

- Entendimento de requisições HTTP (GET, POST, PUT, DELETE)
- Validação de respostas JSON
- Uso do Postman para organização e execução de testes
